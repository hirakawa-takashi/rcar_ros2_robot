# 解説動画（ゆっくり解説）の作り方

ダッシュボードの「▶ 動画」「▶ 解説動画」で出る動画の作り方と、読み上げのきまりです。
動画ファイルは git に入れず、ラズパイの `~/AI-CAR_ws/videos/<slug>_yukkuri.mp4` に置きます
（`architecture.yaml` の `video:` に名前を書くと、ファイルがあるときだけボタンが出ます）。

## しくみ

- 霊夢（左、AquesTalk Pi の声 `f1`）が聞き、魔理沙（右、`f2`、速さ 110）が答える。左右は入れかえない。
- 台本は 1 本ごとに `spec.json`（`slides` と `talk`）。`talk` の 1 行は `text`（字幕）と `read`（読み上げ文）。
- `read` は AquesTalk Pi（ラズパイの `~/aquestalkpi`）で声にする。字幕とスライドは PIL、つなぎは ffmpeg。
- コードのスライドは、リポジトリのファイルの行番号（`lines`・`hl`）で出す。コードが変わって行がずれたら、
  動画を作った時のファイルと今のファイルをくらべて行番号を直してから、作り直す（直すのは 1 回だけ）。

## 読み上げ（read）のきまり

AquesTalk は漢字も読みますが、まちがえる言葉があります。`read` には次のように書きます。

| 書きたいもの | read に書く | まちがった読み |
|---|---|---|
| 1 文字の「値」（この値、高い値 など） | あたい | ね |
| Raspberry Pi・Pi 5 | ラズパイ・ラズパイ5 | パイ・パイ5 |
| ファイル名の `.py` | ドット・パイ | （「パイ」だけにしない） |
| 英語・コード名 | カタカナ（LiDAR → ライダー、Nav2 → ナブツー、YAML → ヤムル） | 英字のまま |
| 単位 | メートル、センチ、秒、度、パーセント、ボルト | m、cm、s など |

- 熟語の「値」（設定値・しきい値・初期値・最大値）は、AquesTalk が「ち」と正しく読むので、そのままでよい。
- 迷ったら、ラズパイで `cd ~/aquestalkpi && ./AquesTalkPi64 -t "読ませたい文"` を実行すると、読み方（音声記号）が出る。
  例: `値を読む` → `ネオ/ヨ'ム`（まちがい）、`設定値` → `セッテ'ー_チ`（正しい）。
- 台本を作ったら、検査（`validate_spec.py`）で「1 文字の値」「パイだけ」が残っていないか確かめる。
