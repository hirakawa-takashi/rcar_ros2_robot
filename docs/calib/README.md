# 2 眼カメラのキャリブレーション

2 眼カメラで距離を測る前に、左右のレンズのゆがみ・向きのずれ・レンズの間隔を測る。

## 用意するもの

- `checkerboard_9x6_24mm_A4.pdf` を A4 横に **100 %（実際のサイズ）** で印刷する。下の線が 100 mm になっているか、定規で確かめる
- 1 マスの大きさを定規で測っておく（24 mm からずれていたら、計算のときに `--square-mm` で直す）
- 印刷した紙は、曲がらないように板や段ボールに平らに貼る

## 撮影（ダッシュボード）

1. 車を止めて、模様をカメラに向けて持つ。左右どちらの目にも模様の全部が入るようにする
2. カメラカードの「キャリブレーション」の「撮影」を押す（API トークンが必要）
   - 左右とも見つかると「保存 N 組目」。見つからないと、見つからなかった側（左・右）が出る
3. 場所と向きを変えて、20 組くらい撮る
   - 画面の真ん中・四すみ・はしにも写す（はしのゆがみを測るため）
   - 近く（約 30 cm）と遠く（約 1.5 m）を混ぜる
   - 左右・上下に 30° くらい傾けたものも混ぜる
   - ぶれないように、押すときは止めて持つ

画像は Pi の `~/AI-CAR_ws/calib/stereo/pair_NNN_left.png` / `pair_NNN_right.png` に保存される（片目 1280×720）。

## 計算（Pi）

```bash
source /opt/ros/jazzy/setup.bash
source ~/AI-CAR_ws/install/setup.bash
ros2 run ai_car_web stereo_calibrate --square-mm 24
```

`~/AI-CAR_ws/calib/stereo/stereo_calib.yaml` に、左右のカメラの値（`K1` `D1` `K2` `D2`）、左右の向きと位置（`R` `T`）、平行化の値（`R1` `R2` `P1` `P2` `Q`）を書く。

よしあしの目安:

- 誤差（`rms_stereo_px`）: 0.5 px 以下ならよい。1 px を超えたら撮り直す
- 平行化後の上下のずれ（`rectified_y_error_px`）: 0.5 px 以下
- レンズの間隔（`baseline_m`）: 約 0.060 m
- 広角でゆがみが大きく誤差が下がらないときは `--rational` を付ける

## 距離の計算（stereo_depth_node）

- `stereo_calib.yaml` ができると、`stereo_depth_node` が自動で読む（ファイルが変わると読み直す。再起動はいらない）
- ダッシュボードのカメラカードの「2眼の距離」に、通り道の中のいちばん近い物の距離が出る。「距離の画像」を押すと、映像が距離の色（近い = 赤、遠い = 青、測れない = 黒）に変わる
- 「2眼の距離」の行にマウスを乗せると、床の高さ（中央値）が出る。0 m から 2 cm 以上ずれるときは、`dashboard.yaml` の `stereo_depth_node` の `camera_height_m`・`camera_pitch_deg` を合わせる
- 白い壁・ガラス・真っ暗な所は、左右で同じ所が見つからず測れない（黒くなる）
